# multiflexi.eu

MultiFlexi Hub WebSite - a catalog of MultiFlexi applications and credential types.

![Screenshot](index.png?raw=true)

## Features

- **Applications catalog** — browse, search, and filter applications by tags
- **Credential Types catalog** — browse, search, and filter credential types by topics with homepage links
- **Card & Table views** — toggle between card grid and DataTable views with persistent preference
- **Import/Export** — import credential prototypes from JSON, export for sharing
- **Internationalization** — full i18n with language switcher
- **Coworker management** — share editing access to credential types
